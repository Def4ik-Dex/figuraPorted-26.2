# Figura (Unofficial Port to Minecraft 26.2 ONLY FABRIC!!)

This is an unofficial port of the **Figura** mod from version `1.21.11 dev` to Minecraft `26.2`.

Original project: [FiguraMC/Figura](https://github.com/FiguraMC/Figura)

## 📌 About
Figura is a powerful Minecraft mod that allows players to fully customize their avatar models, animations, and sound effects using custom models and Lua scripting. This repository contains the source code ported for compatibility with Minecraft `26.2`.

## ⚙️ Project Status
* **Minecraft Version:** 26.2
* **Target Loader:** [Fabric]
* **Status:** The experimental one works

## 📥 Downloads
You can find pre-built binaries (`.jar` files) in the **[Releases](../../releases)** section.

## 🛠 Building from Source
To build the project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone [https://github.com/YOUR_USERNAME/Figura.git](https://github.com/Def4ik-Dex/Figura.git)
   cd Figura

    Build with Gradle:
    Bash

    ./gradlew build

    The compiled .jar file will be generated in the build/libs/ directory.
